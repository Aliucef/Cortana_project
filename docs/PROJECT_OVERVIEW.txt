PROJECT SUMMARY
===============

Cortana is a multi-agent AI assistant designed to help users manage their daily lives through conversational interfaces. The system integrates multiple specialized agents (Finance, Fitness, News) with advanced AI capabilities including Retrieval-Augmented Generation (RAG) and intelligent intent classification to provide personalized, context-aware assistance.


CORE CONCEPT
============

Traditional AI assistants provide generic responses without understanding personal context. Cortana addresses this by:

1. Maintaining a dual-layer knowledge system:
   - General knowledge base (exercise guides, nutrition advice, financial tips)
   - Personal context layer (user's workout logs, spending patterns, progress tracking)

2. Intelligent intent routing that understands natural language and routes queries to appropriate specialized agents

3. Multi-modal interaction supporting text, voice commands, and Telegram bot interface


TECHNICAL ARCHITECTURE
======================

Backend Framework:
- FastAPI (Python) - High-performance async REST API
- PostgreSQL - Relational database for structured data
- SQLAlchemy ORM - Database abstraction layer

AI Services:
- Groq AI (Primary) - Fast cloud-based LLM for conversational AI
- Ollama (Fallback) - Local LLM for offline capability
- Gemini (Fallback) - Google's generative AI as final fallback

RAG System:
- FAISS - Vector similarity search for knowledge retrieval
- Sentence Transformers - Text embedding model (all-MiniLM-L6-v2)
- Dual vector stores: General knowledge + Personal context

Intent Classification:
- AI-powered intent classifier (6 intent types)
- Natural language understanding for query routing
- Dynamic routing to specialized handlers

Integration Points:
- Telegram Bot - Primary user interface
- Twilio - Voice/SMS notifications
- APScheduler - Background task scheduling

CHALLENGES OVERCOME
===================

1. AI Response Truncation
   Problem: Responses cutting off mid-sentence
   Solution: Identified and fixed low token limits in AI service (150 -> 1000)

2. Intent Misclassification
   Problem: Keyword matching missing 70% of queries
   Solution: Implemented AI-based intent classification with 95% accuracy

3. Generic Responses
   Problem: AI providing generic advice without personal context
   Solution: Built dual-layer RAG system prioritizing user's actual data

4. Database Enum Mismatches
   Problem: SQLAlchemy storing enum names instead of values
   Solution: Used values_callable to force enum value storage

5. Workout Schedule Randomness
   Problem: Concern about AI generating random workouts
   Solution: Clarified template-based generation with database persistence

6. Day Detection Not Working
   Problem: Always showing current day regardless of user query
   Solution: Implemented day keyword parsing with tomorrow calculation


INNOVATION ASPECTS
==================

1. Dual-Layer RAG Architecture
   Novel approach combining static knowledge base with dynamic personal context, prioritizing user's actual data over generic advice.

2. AI Intent Classification for Agent Routing
   Using LLM for intent classification rather than rule-based systems, achieving higher accuracy with natural language flexibility.

3. Template-Based Workout Generation with Context
   Rule-based program generation that considers multiple user factors (goal, injuries, equipment, experience) rather than purely AI-generated plans.

4. Progressive Fallback AI Architecture
   Three-tier AI system (Groq cloud -> Ollama local -> Gemini cloud) ensuring high availability with cost optimization.

5. Conversational Expense Logging
   Natural language processing for expense entry without rigid form structures, improving user experience and adoption.
