# Health Pages Content Distribution Plan

## 1. /health (Overview & Stats)
- Stats Cards (Total Workouts, Streak, This Week, Weight)
- Timer Quick Access Cards
- Quick summary/welcome message

## 2. /health/workouts (Today's Workouts)
- This Week's Workouts Section
- Workout cards with exercises
- Mark complete functionality
- Edit/Delete workout options
- Workout logging modal
- Custom workout modal

## 3. /health/history (Workout History)
- Workout History Section
- Search and filter
- Pagination
- History detail modal
- Export functionality

## 4. /health/create (Create Workouts)
- Custom Workout Creation Section
- Workout Templates Section
- Exercise selection from library
- Save/Schedule workout

## 5. /health/library (Exercise Library)
- Exercise Library Section
- Category filters
- Equipment filters
- Difficulty filters
- Exercise detail modal
- Search functionality

## 6. /health/goals (Fitness Goals)
- Fitness Goals Section
- Add/Edit goal modals
- Goal progress tracking
- Goal cards with progress bars

## 7. /health/progress (Progress Tracking)
- Progress Charts Section
- Personal Records Section
- Body Measurements Section
- Calendar View Section
- Workout Notes Section

## 8. /health/rest (Rest Days)
- Rest Day Scheduler Section
- Active recovery suggestions
- Rest day tracking

## Shared Components/Utils Needed
- API functions (lib/health-api.ts)
- Dark mode hook
- Common modals
- Loading states
